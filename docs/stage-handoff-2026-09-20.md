# 网站阶段交接说明

日期：2026-09-20
范围：当前本地代码与内容规范。本文不是线上版本一致性证明。

## 1. 产品与课程

- 产品为新概念英语中译英默写工具：选册、选课、预览、练习、结算、错题复习。
- 首页提供四册入口；第一、二册已有内容，第三、四册仍为待导入状态。课数、句数应读取实际内容，不能使用设计稿示例数值。
- 首页支持明暗主题、书籍封面、课程统计与课程进入按钮。
- 课程列表显示学习进度、正确率、最近学习状态；返回列表保留入口滚动位置。
- 课文预览包含目录、英文、中文、学习状态、历史错题入口与开始练习。

## 3. 练习与交互

- 默认显示当前中文提示，以英文原文为答案基准，每个词项对应一个输入格。
- 错误词保留原输入并标红；开始重新输入时替换错误词，方便对照和纠错。
- 修正多个错误词后，空格应按纠错状态提交，不要求移到整句最后一格；相关回归脚本见下文。
- 左右方向键切换输入格；空格推进输入或提交；空格键的处理取决于当前输入状态。
- 空输入格按 Backspace 可退到上一格，第一格为边界。
- Alt / macOS Option 控制答案显示；答对后的同一操作为再来一次。
- 单独按下并松开 Ctrl 播放当前句；Ctrl+M 标记掌握；Shift+左右方向键切题；答对后 Enter 下一题。
- 校验成功后先播放简短正确音效，再朗读当前英文句子。
- 解析展示逐词音标、语境义、词性及静态句子结构。词性与句子成分相互独立。
- 支持暂停、继续；未完成时退出需二次确认。确认退出清除当次会话并恢复开练前的课文记录，不清除此前完成的历史。
- 操作栏采用随页面内容伸展的布局；窗口过矮时可滚动查看，不能遮挡正文。

## 4. 学习记录与统计口径

- 当前为静态网站加 localStorage，本地记录可以跨刷新、关闭后重开保留。
- 记录受浏览器、配置文件及站点来源隔离；本地 file 页面和线上域名不能视作共享记录。当前没有账号云同步；清理站点数据会丢失本地记录。
- 学习数据包括课程进度、完成状态、最近时间、得分/练习结果、历史错句、生词字段和会话草稿等。存在字段不代表存在独立的生词管理产品界面。
- 正确率实现：成功答对且非手动掌握的结果数 ÷ 累计提交尝试次数，四舍五入为百分比，无提交时为 0%。
- 一次命中率与正确率是不同指标；最终全部答对不意味着正确率为 100%。例如 7 题合计提交 10 次并全部答对，提交正确率为 70%。
- 历史错题可从课文预览查看并复习；错题复习结算独立，不覆盖原整课结算。
- 学习数据更新必须保持课程、会话与错题复习之间的边界，不能用展示上的示例数替代真实统计。

## 5. 英文原文导入约定

用户可以只提供英文原文，由内容制作环节补齐数据。页面的 JSON 导入与这项内容制作工作不是同一个步骤；浏览器不会自动把未经处理的英文生成完整题库。

标准流程：

1. 识别课程、课号、标题、段落和对话顺序，保留原文。
2. 拆为练习句或符合规范的长句片段。
3. 生成与每题英文对应的自然中文提示。
4. 生成词项、标点归属、音标、语境中文义、词性及类别。
5. 生成句子结构分组、范围和父子关系。
6. 生成三层提示：场景记忆提示、首字母遮罩、完整答案及轻量说明。
7. 校验完整性，抽查复杂句，保留人工修订，固化静态内容版本。
8. 接入页面、检查练习和解析展示，经确认后发布。

三层提示属于内容规范；不能据此宣称当前每册均已完成全部提示数据或独立提示按钮。

## 6. 导入后的应用规则

- 顺序：原文是唯一顺序来源，不调换、不擅自改写；标题、说话人标签通常不作为答案。
- 拆句：以句末标点为主，避免误拆 Mr.、Dr. 等缩写。超过 14 词的复合句可在逗号/分号处按完整语义拆分；不是逢逗号必拆。少于 3 词的碎片与邻段合并。
- 对齐：拆分后中英文必须一一对应；保留原句关联 `parentSentenceId` 和片段后缀，浏览器不临时拆句。
- 输入格：缩写如 isn't、Here's 为一个词项；标点归属词项，不独占输入格；tokenIndex 从 0 连续排列。
- 词义：必须符合当前语境。复合词、固定短语和专名需专项检查，不能把“待释义”当作内容完成。
- 结构：用闭区间 [startToken, endToken]，子组不越父组、同父组不重叠、顶层完整覆盖。词性不能代替主谓宾等结构角色。
- 生成时机：翻译、词义、结构等在发布前生成、校验并保存，前端只读取。
- 人工优先：`analysisSource: human` 不得批量覆盖；Lesson 3 人工结构组为权威覆盖层。
- 身份稳定：修订文字保留课程、课文、句子、词项 ID，通过 revision 递增追踪版本。
- 审核：机器标注覆盖率不是语法准确率；复杂句、倒装、省略、多义句需抽查。不能以“无缺失”宣称逐句人工审校完成。

详细实施基线以 `docs/content-import-and-analysis-spec.md` 为准。

## 7. 文件与库表

- `index.html`：页面、样式、交互、学习记录、预览与练习语音逻辑，当前仍集中在单文件。
- `nce1-zh-supplement.js`、`nce1-analysis.js`：第一册补充数据和静态结构。
- `nce2-content.js`：第二册浏览器内容数据。
- `assets/ui/home/slices/`：首页素材；构建脚本会复制整个目录。
- `schemas/course-content.schema.json`：统一内容交换格式。
- `content/course-content-template.v1.json`：内容包模板；包阶段为 raw、enriched、approved。
- `database/schema.postgres.sql`：未来 PostgreSQL 参考设计，目前不是已运行的后端。
- 内容表：course_series、course_revisions、lessons、sentences、sentence_tokens、sentence_analysis_groups、sentence_hints、content_import_jobs。
- 学习表：learner_profiles、practice_sessions、answer_attempts、sentence_mastery、lesson_progress。
- 后续服务端记录应关联具体内容版本，防止课文修订后历史统计错位。
